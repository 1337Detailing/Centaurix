05 / FAQ

Questions?
We keep it simple.

Is Centaurix free? +

Yes. The project is available for free on GitHub.

Which devices are supported? +

Centaurix is designed for the Lost Vape Centaurus BT200. Some Bluetooth commands depend on your device firmware.

How accurate is daily puff tracking? +

Tracking uses the device's cumulative counter. Puffs recorded while disconnected across midnight cannot be assigned to a specific day with certainty.

How do I install a GitHub Actions build? +

Open a completed build, download its ZIP under “Artifacts”, extract the APK and install it. Releases provide a direct APK download when available.

Is this an official Lost Vape app? +

No. Centaurix is an independent project and is not affiliated with Lost Vape.
